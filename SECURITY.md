# Security policy

## Supported versions

During pre-alpha development, only the latest commit on `main` receives security fixes. Published support windows will be documented before the first stable release.

## Reporting a vulnerability

Use GitHub private vulnerability reporting for this repository. Do not open a public issue or disclose details before a coordinated release. Include affected versions, impact, reproduction steps, and any proposed mitigation.

We aim to acknowledge reports within three business days, triage them within seven calendar days, and provide a remediation plan within fourteen calendar days. These targets are project goals, not warranties.
