# SCD-0030: Azure Key Vault rejected the request

- Slug: `azure-keyvault-unauthorized`
- Severity: `error`

## Explanation

Key Vault returned HTTP 401 Unauthorized, so the requested certificate source is unavailable. Only the HTTP status and vault host are reported; credential and raw error text are never logged.

## Remediation

Run az login or configure the supported Azure default credential environment, then verify the vault URI.
