# SCD-0023: Fixed renewBefore is not shorter than the issued lifetime

- Slug: `renew-before-exceeds-lifetime`
- Severity: `warning`

## Explanation

A cert-manager Certificate sets spec.renewBefore to a value at or beyond the actual issued lifetime (status.notBefore to status.notAfter, or the Secret leaf), so cert-manager renews in a loop. cert-manager requires spec.duration to be greater than spec.renewBefore.

## Remediation

Set spec.renewBeforePercentage instead of a fixed spec.renewBefore, so renewal follows the actual issued duration.
