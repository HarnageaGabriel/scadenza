# SCD-0025: Requested duration exceeds the next public-CA lifetime

- Slug: `duration-exceeds-next-limit`
- Severity: `warning`

## Explanation

A cert-manager Certificate with an ACME issuer on a known public CA directory requests a spec.duration longer than the CA/B maximum validity that governs the next issuance, chosen at the evaluation instant (--now) as the next scheduled step, or the step in force when no further step remains. When spec.duration is absent, cert-manager's documented 90-day default is used and recorded as the evidence fact duration-source=default. The public CA will issue a shorter lifetime than requested. An unknown ACME server produces no finding, only evidence.

## Remediation

Set spec.duration no longer than the next CA/B maximum validity, or confirm the issuer is a private CA.
