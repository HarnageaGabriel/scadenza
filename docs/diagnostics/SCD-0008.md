# SCD-0008: Wildcard certificate name was not probed

- Slug: `wildcard-name-not-probed`
- Severity: `warning`

## Explanation

A wildcard subject name was derived from Certificate Transparency. A wildcard covers no single host, so scadenza listed it as unresolved instead of guessing a host name.

## Remediation

Name a concrete host with --host to check the wildcard certificate.
