# SCD-0024: Fixed renewBefore reaches the next shorter lifetime

- Slug: `renew-before-loop-at-next-limit`
- Severity: `warning`

## Explanation

A fixed spec.renewBefore is at or beyond the next CA/B maximum validity, or the next announced Let's Encrypt lifetime for an ACME issuer on acme-v02.api.letsencrypt.org. Renewal will loop once the shorter lifetime takes effect; the risk records the effective date.

## Remediation

Set spec.renewBeforePercentage so the renewal point follows the actual issued duration.
