# SCD-0033: An Azure Key Vault certificate was skipped

- Slug: `azure-keyvault-item-skipped`
- Severity: `warning`

## Explanation

One certificate could not be read (not found after listing, no issued certificate yet, or an invalid response) and was left out, so the scan is partial. Only the HTTP status, when there is one, and the vault host are reported.

## Remediation

Check the certificate in the vault; a pending or deleted certificate needs no action.
