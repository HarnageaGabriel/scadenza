# SCD-0035: Run reached the maximum duration

- Slug: `scan-deadline-exceeded`
- Severity: `warning`

## Explanation

The run reached the maximum duration and stopped every outstanding request. What was collected is still reported. A source that did not finish is partial, or failed when it produced nothing, and a target that was not probed is counted as not checked. The run is incomplete, not clean.

## Remediation

Raise the maximum duration, or narrow the scope, so the run finishes inside the limit. The exit code follows the ordinary rules, so an incomplete scan exits 5 with --strict or --min-coverage.
