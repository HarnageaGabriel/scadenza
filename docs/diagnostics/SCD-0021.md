# SCD-0021: Invalid --fail-on kind

- Slug: `invalid-fail-on-kind`
- Severity: `error`

## Explanation

The --fail-on value listed a kind that is not one of ct_only, live_only, exceeds-100d, not-compliant-at-issuance, or none, or combined none with another kind.

## Remediation

Use only the documented kinds; pass none alone to disable exit 3.
