# SCD-0015: Kubernetes read access was forbidden

- Slug: `kube-forbidden`
- Severity: `warning`

## Explanation

Kubernetes RBAC refused a read. Structured fields name the resource kind, namespace, HTTP status, and StatusReason. This is a partial failure when another requested resource kind was read successfully.

## Remediation

Grant the default read-only ClusterRole for certificates, issuers, clusterissuers, and namespaces. Grant Secret list/get only when metadata or certificate data reads are explicitly intended.
