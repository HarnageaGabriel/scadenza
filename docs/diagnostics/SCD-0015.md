# SCD-0015: Kubernetes read access was forbidden

- Slug: `kube-forbidden`
- Severity: `warning`

## Explanation

Kubernetes RBAC refused a read. The detail names the resource kind whose list was denied; other kinds may still have been read, so this is a partial failure.

## Remediation

Grant the documented read-only ClusterRole with list/get on secrets, certificates, issuers, clusterissuers, and namespaces.
