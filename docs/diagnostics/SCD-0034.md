# SCD-0034: Certificate Transparency result stopped at the entry cap

- Slug: `ct-result-truncated`
- Severity: `warning`

## Explanation

A Certificate Transparency query collected more entries than the entry cap allows, so the result stops at the cap and the source is reported as partial. The issuances after the cap were not read.

## Remediation

Scan a narrower scope, such as a single subdomain, or query the Certificate Transparency source directly for the issuances beyond the cap.
