# SCD-0027: Manual renewal falls after the next CA/B step

- Slug: `manual-renewal-after-limit`
- Severity: `warning`

## Explanation

An operator declared a domain as manually renewed in scadenza.yaml, and the certificate's notAfter falls after the next CA/B maximum validity step, so the manual renewal workload grows.

## Remediation

Move the certificate to an automatic renewal mechanism, or plan the additional manual renewals per year.
