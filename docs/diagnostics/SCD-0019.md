# SCD-0019: Ownership file could not be used

- Slug: `ownership-file-invalid`
- Severity: `error`

## Explanation

The --ownership-file could not be read or did not match the documented schema. Owner resolution is not attempted from an invalid file, so no owner is inferred.

## Remediation

Fix the YAML so it contains only labelKeys, domains, and namespaces, and give every value a non-empty string.
