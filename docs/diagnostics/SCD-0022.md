# SCD-0022: Configuration file could not be used

- Slug: `config-invalid`
- Severity: `error`

## Explanation

The --config file could not be read, did not decode as strict YAML version 1, or set a value outside its documented range. Nothing is auto-loaded, so only an explicit --config is read.

## Remediation

Fix the file to match docs/configuration.md; only known keys with valid values are accepted.
