# SCD-0018: cert-manager custom resources are not installed

- Slug: `cert-manager-crd-missing`
- Severity: `info`

## Explanation

The cert-manager.io/v1 custom resource definitions could not be listed, so cert-manager Certificates were skipped. TLS Secrets were still read.

## Remediation

Install cert-manager to include Certificate, Issuer, and ClusterIssuer observations, or accept TLS Secrets only.
