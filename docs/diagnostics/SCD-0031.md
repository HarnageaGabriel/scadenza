# SCD-0031: Azure Key Vault read was partially forbidden

- Slug: `azure-keyvault-forbidden`
- Severity: `warning`

## Explanation

HTTP 403 Forbidden on a certificate or policy read skips that certificate and makes the scan partial. HTTP 403 while listing a vault means that vault is not read; when no vault could be read, coverage is failed. Only the HTTP status and vault host are reported.

## Remediation

Grant the verified built-in Key Vault Reader role at vault scope, or legacy certificate get and list permissions; never grant secret-value access for scadenza.
