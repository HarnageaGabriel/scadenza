# SCD-0016: TLS secret holds no certificate

- Slug: `secret-without-certificate`
- Severity: `warning`

## Explanation

A secret of type kubernetes.io/tls was read but contained no tls.crt data, so no certificate could be parsed from it. The private key is never read.

## Remediation

Confirm the secret is a complete kubernetes.io/tls secret, or remove it when it is stale.
