# SCD-0028: Kubernetes Secret data reads are enabled

- Slug: `kube-secret-data-read`
- Severity: `info`

## Explanation

The --kube-secrets flag or kube.secrets configuration enables full kubernetes.io/tls Secret reads so scadenza can parse tls.crt and compute fingerprints. Secret private keys are dropped immediately and are never retained. The diagnostic detail identifies every namespace whose Secret data may be read.

## Remediation

Remove --kube-secrets or set kube.secrets to false when Secret metadata and cert-manager status are sufficient.
