# SCD-0028: cert-manager Certificate spec value is invalid

- Slug: `renewal-config-invalid`
- Severity: `warning`

## Explanation

A cert-manager Certificate sets spec.duration, spec.renewBefore, or spec.renewBeforePercentage to a value cert-manager's own validation rejects. spec.duration must be at least 1h, the effective spec.renewBefore must be at least 5m, spec.duration must be greater than spec.renewBefore, and spec.renewBeforePercentage must be an integer percentage between 1 and 99 of the actual issued lifetime.

## Remediation

Fix the Certificate spec so cert-manager accepts it; spec.renewBeforePercentage is computed from the actual issued lifetime, which is what keeps renewal working as lifetimes shorten.
