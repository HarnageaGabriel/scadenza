# SCD-0032: Azure Key Vault source is unavailable

- Slug: `azure-keyvault-unreachable`
- Severity: `error`

## Explanation

The vault could not be read because the default credential chain failed, the connection failed, the response was invalid, or the context ended. Only a safe classification and vault host are reported.

## Remediation

Verify network access, DNS, the vault URI, and az login or the supported Azure default credential environment.
