# SCD-0010: TLS probe failed

- Slug: `tls-probe-failed`
- Severity: `warning`

## Explanation

A TLS handshake could not be completed. The detail names the host and the failure class, one of dns, connect-timeout, refused, canceled, tls-alert, no-certificate, or handshake-failed.

## Remediation

Check the host name, network reachability, and whether the endpoint serves TLS on the probed port.
