# SCD-0010: TLS probe failed

- Slug: `tls-probe-failed`
- Severity: `warning`

## Explanation

A TLS handshake could not be completed. The detail names the host and the failure class, one of dns, connect-timeout, refused, canceled, tls-alert, no-certificate, handshake-failed, or blocked-address. The blocked-address class means that every resolved address of a Certificate Transparency derived host was a special address (loopback, link-local, multicast, or unspecified), so no address was dialed.

## Remediation

Check the host name, network reachability, and whether the endpoint serves TLS on the probed port.
