## Unreleased
- Add M4a reliable results to `scadenza scan` (ADR 0006): a `coverage` object (`targets_requested`, `targets_probed`, `targets_failed`, `names_not_checked`, per-source `sources` with `ok`/`partial`/`failed`/`not_requested`, and `ratio`) so a partial scan never looks clean, plus a one-line coverage summary in the table; `--strict` and `--min-coverage <0-100>` exit 5 (`SCD-0020`) for an incomplete scan; `--fail-on` selects which finding kinds cause exit 3, defaulting to `live_only,not-compliant-at-issuance` so `ct_only` (noisy on CDNs) and `exceeds-100d` (a readiness signal) are reported but do not fail by default; a dated `internal/policy` table (398 days before 2026-03-15, then 200/100/47 from 2026-03-15/2027-03-15/2029-03-15, SC-081v3) exposed per certificate as `policy` with `compliant_at_issuance`, `next_limit_days`, `next_limit_effective`, and `fits_next_limit`; `--now RFC3339` on `ct` and `scan` fixing the evaluation instant and `generated_at`; per-certificate `correlation_method` (`sha256`, `issuer_serial`, or `unresolved`, the weakest evidence); a strict `scadenza.yaml` via explicit `--config` (flags win, `SCD-0022`/`SCD-0021` on bad input); `not-compliant-at-issuance` findings; new diagnostics `SCD-0020`-`SCD-0022`; and JSON contract tests validating every scenario against `docs/schema/*.json`. Adds `docs/configuration.md`, `docs/adr/0007-json-compatibility.md`, and the documented exit precedence `2 > 4 > 3 > 5 > 0`.
- Fix M3 review findings: never copy raw Kubernetes client/API error text into diagnostics or `Problem.Detail` (emit HTTP status, `StatusReason`, resource kind, and namespace only) and scrub `tls.key` from any non-nil list before checking the list error; treat `401 Unauthorized` as an unavailable Kubernetes source and keep `SCD-0015` for partial `403` reads, tracking successful list operations per resource kind so an empty successful list still counts as a read; stop a nil `public` from forcing `not_applicable` and report `public: true` when any observation proved trust; restore `namespace-annotation` provenance in `owner.Source`, its schema enum, and rendering; always render JSON arrays as `[]` rather than `null` in `scadenza ct` and `scadenza scan`; restrict `SCD-0018` to cert-manager discovery failures and reject colliding normalized ownership keys; accept only `Issuer`/`ClusterIssuer` with exactly one recognized map-valued issuer spec key; check cancellation while paging; and run the Kubernetes e2e under the read-only ServiceAccount token, asserting denied write verbs and scanning stderr for leaked key material.
- Fix M2 review findings on `scadenza scan`: verify IP-literal probes against the probed IP so a chain for an unrelated public name is no longer reported trusted (ADR 0004); keep explicitly named targets when `--max-hosts` trims CT-derived hosts only; return exit 4 only when every selected external source failed and always render the document first; dial the addresses already resolved instead of resolving a second time; probe CT-derived hosts on the configured `--port`; require a `ct_only` name to have been probed and observed live as served by that host; strip control characters from table cells and reject them in the endpoint parser; surface `SystemCertPool` errors in `verify_error`; classify refused connections with `errors.Is` and add a `canceled` probe-error class; strip a UTF-8 BOM from hosts files and a trailing dot from names; emit the `SCD-0007` fallback diagnostic only after the fallback source succeeded.
- Add a read-only Kubernetes source to `scadenza scan` (`--kube`): read `kubernetes.io/tls` Secrets (only `tls.crt`, key never touched) and cert-manager `Certificate` resources with client-go and a dynamic client, merge them by SHA-256 fingerprint into the existing inventory, report issuer type and renewal facts, and resolve owners only from labels, annotations, namespaces, or an optional mapping file. Additive `scadenza.scan/v1` fields (`owners`, `kubernetes`, `sources_used: kube`, `verdict_100d: not_applicable`, `kube_only`), diagnostics `SCD-0014`-`SCD-0019`, a minimal ClusterRole in `deploy/rbac/`, ADR 0005, and a kind + cert-manager CI workflow.- Add `scadenza scan`: correlate Certificate Transparency issuances with live TLS handshakes by SHA-256 fingerprint, report expected-versus-observed differences, probe explicitly named hosts only (wildcards listed as unresolved, `--max-hosts` cap), and emit table/JSON/CSV following `scadenza.scan/v1`.
- Fix M1 review findings: redirect and Authorization hardening, strict Cert Spotter pagination and limits, exact 100-day verdict, CSV formula-injection guard, bounded Retry-After handling (delta-seconds and HTTP-date), total sort order, internal-error exit code, inverted-validity rejection, typed diagnostic schema, and scorecard SARIF upload.
- Add `scadenza ct <domain>` with Cert Spotter and crt.sh fallback, deterministic table/JSON/CSV output, bounded HTTP behavior, diagnostics, schemas, and offline fixtures.
- Repository bootstrap and study notes.
